# AK Digital Services — Free Website

This is a responsive static website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year and demo contact form
- `assets/prototype.jpg` — prototype background image

## Publish for free with GitHub Pages
1. Create a free GitHub account.
2. Create a **public** repository, e.g. `ak-digital-services`.
3. Upload all files while preserving the `assets` folder.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/root`, then Save.
7. GitHub will give you a free `github.io` website address.

## Before publishing
Replace:
- `your-email@example.com`
- `+91 XXXXX XXXXX`
- sample testimonials
- sample portfolio projects
- placeholder branding/content

For a real contact form, connect Formspree or EmailJS.
